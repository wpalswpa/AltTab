# 배포 화면 보존

## 목적과 범위

배포 서버가 중단되어도 저장소 방문자가 PassFinder의 화면과 학습 흐름을 확인할 수 있도록 한다. 공개 배포 화면을 PNG로 보존하고 README에서 직접 보여 준다. 제출 당시 개인 학습 화면과 후속 v2를 구분한다. 동결된 제출 PRD와 서비스 코드는 변경하지 않는다.

## 보존 기준

- 대상은 `https://alt-tab-mu.vercel.app/`의 공개 화면이다. 로컬 재현이나 조작한 화면으로 대체하지 않는다.
- 첫 화면, 학습 워크스페이스, PDF 선택, 샘플 풀이·결과·오답 복습, v2 목록·생성 입력·응시 안내·모바일 화면을 보존한다.
- 브라우저의 샘플 체험은 실제 AI 생성과 구분한다. v2 응시 시작·제출과 AI 생성은 이번 캡처에서 실행하지 않는다.
- 로그인 입력, 토큰, 실제 학생의 성적·닉네임은 캡처 대상에서 제외한다.
- 이미지에 설명·출처·캡처 날짜를 붙인다. 원본 파일의 크기·해시·캡처 시각(KST)은 `screenshots/manifest.json`에 기록한다.
- README 이미지와 문서 링크의 존재, PNG 열기, 원격 저장소 반영을 확인한다. 화면 캡처를 서비스 전체 검증이나 사용자 성과로 해석하지 않는다.

## 화면 기록

2026-10-03 배포 화면을 보존했다. 화면별 설명은 [README](../README.md)의 화면 기록을 따른다. 샘플 5문제를 풀어 4문제 정답 결과와 오답 1문제 복습 화면을 확인했다. 해당 샘플 결과는 브라우저 내부 기록이며 Supabase 저장·AI 문항 정확성의 증거가 아니다.

v2는 배포 주소에서 시험 목록과 생성 입력 화면을 확인했다. 서버·DB 저장 및 순위 규칙은 [v2 설계](v2.md)를 따른다. 이번 보존 작업에서는 새 응시 기록을 만들지 않고 AI를 재호출하지 않았다.
