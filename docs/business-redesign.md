# PassFinder 사업화 재설계

기준일: 2026-10-07 · 범위: 설계와 사업계획만. 코드는 고치지 않았다.

대회 뒤 심사위원(해커톤 수상 뒤 창업한 교수)이 서면으로 보낸 피드백을 PassFinder의 사업 설계에 적용한 문서다. 결론은 세 가지다. ① 학생이 교안을 올리는 구조는 저작권 문제가 있어 그대로 키울 수 없다. ② 교수자·교육기관이 자기 자료로 문제를 만드는 B2B 출제 도구로 방향을 바꾸면 권리 문제를 구조로 해결할 수 있다. ③ 다만 대학 좌석 판매만으로는 시장이 작다는 계산이 나와서, 에듀테크 기업에 출제 기능을 API로 공급하는 매출 축이 함께 필요하다.

표시 규칙: [사실] 원천 확인, [계산] 아래 가정으로 계산, [가정] 검증 전 숫자, [미확인] 확인 방법만 있음.

## 1. 받은 피드백과 판단

| 피드백 | 판단 | 이유 |
|---|---|---|
| 학생 필요가 분명한 서비스 | 수용, 단 지불 의사는 미검증 | 대회 당일 팀 외 사용자 시험을 하지 않았다. 필요와 구매는 다르다 |
| 교안을 그대로 쓰면 저작권·개인정보 문제 | 수용 | 아래 2절. 학생 업로드 구조에서는 권리자 확인이 불가능하다 |
| 온톨로지·유형별 고도화한 출제 솔루션, 에이전트·API | 수용하되 순서 조정 | 온톨로지는 처음부터 크게 만들지 않는다. 과목 하나에서 개념 목록과 문제 유형 표로 시작해 효과를 잰 뒤 늘린다 |
| 동의 절차와 비식별화를 발표 자료에 | 수용 | 3절 |
| 페르미 추정 → KPI → MVP 비용 → 투자금 → 마스터플랜 | 수용 | 4~7절. 계산 결과 대학 B2B 단독 시장이 작아 수익 구조를 수정했다 |
| 교육기관·에듀테크 B2B에서 출발 | 수용 | 대학은 신뢰 확보용 첫 고객, 매출은 API 쪽에 기대를 둔다. 둘 다 가설 |

## 2. 저작권: 누가 자료를 넣는가를 바꾼다

[사실] 강의 자료는 작성한 교수자의 저작물이다. 수강생이 강의 자료를 본인 외 제3자에게 전송하거나 게시하는 것은 저작권 침해가 될 수 있다(문화체육관광부 대학생 저작권 안내, [한경 2024-04 보도](https://magazine.hankyung.com/business/article/202404163741b)). 학생 개인이 자기 공부용으로 쓰는 범위와, 서비스가 그 자료를 받아 저장하고 문항을 만들어 다른 사람과 공유하는 범위는 다르다. 후자는 서비스 운영자가 복제·전송의 당사자가 된다. [미확인] 개인 학습용 AI 처리의 적법 범위는 법률 자문으로 확인해야 한다.

| 구조 | 자료를 넣는 사람 | 권리 확인 | 판단 |
|---|---|---|---|
| 대회 제출판(B2C) | 학생 | 불가능. 누구의 자료인지 서비스가 알 수 없음 | 확장 중지 |
| 재설계(B2B 출제 도구) | 교수자 본인 또는 기관 | 이용약관에서 권리 보유를 확인받고 기관 계약으로 책임 구분 | 채택 |
| API 공급 | 에듀테크 기업(자기 콘텐츠) | 고객사가 권리를 보유한 콘텐츠만 처리하도록 계약 | 채택 |

설계 규칙
- 원문을 문항에 그대로 길게 옮기지 않는다. 문항은 개념과 유형에서 만들고, 근거는 "교안 n쪽" 위치로만 연결한다.
- 생성 문항의 이용 범위는 자료를 넣은 교수자의 강의 안으로 한정한다. 다른 강의·외부 공개는 교수자가 직접 켠다.
- 교안 원문은 문항 생성 뒤 정해진 기간만 보관하고 삭제한다. [가정] 30일. 교수자가 즉시 삭제할 수 있게 한다.

### 온톨로지·유형 고도화의 최소 형태

교수 제안의 핵심은 "교안 문장을 바꿔 쓰는 생성기"가 아니라 "과목의 개념 구조와 문제 유형을 아는 출제기"다. 첫 단계는 데이터베이스 표 두 개면 된다.

| 표 | 내용 | 예 |
|---|---|---|
| 개념 | 개념 이름, 선수 개념, 흔한 오개념 | 정규화 → 선수: 함수 종속 / 오개념: 3NF면 중복이 전혀 없다 |
| 문제 유형 | 개념 확인, 적용, 비교, 계산, 사례 판단 | "다음 테이블을 3NF로 바꾼 결과로 옳은 것" |

오답 선지를 오개념에서 만들면, 학생이 틀린 이유가 개념 단위로 남아 교수자가 다음 수업에서 무엇을 다시 설명할지 알 수 있다. 이것이 학생 혼자 쓰는 범용 AI 챗봇과 구별되는 지점이다. [가설] 교수자가 이 정보를 원하는지는 4절 시험에서 확인한다.

## 3. 개인정보 동의와 비식별화

수집하는 정보를 줄이는 것이 첫 번째 방어다. 학생 실명·학번을 서비스가 받지 않고, 기관이 발급한 가명 ID로만 구분한다.

| 정보 | 수집 여부 | 동의 | 보관과 처리 |
|---|---|---|---|
| 교수자 이름·이메일 | 수집 | 서비스 이용 필수 동의 | 계약 기간 + 정산 의무 기간 |
| 학생 식별 | 기관 가명 ID만 | 기관이 학칙·수업 안내로 고지, 서비스는 필수 동의 | 실명 대응표는 기관만 보유 |
| 풀이 기록·정답 여부 | 수집 | 필수(채점 기능 자체) | 학기 종료 후 [가정] 6개월 뒤 삭제 |
| 학습 통계의 서비스 개선 활용 | 선택 | 별도 선택 동의, 거부해도 이용 가능 | 가명 처리 후 집계만 사용 |
| 교안 원문 | 수집 | 교수자 권리 보유 확인 | 문항 생성 뒤 [가정] 30일 삭제 |
| AI 공급자 전송 | 교안 텍스트만 | 국외 처리 사실과 공급자 고지 | 학생 정보는 보내지 않음. 공급자의 학습 미사용 조건 확인 |

비식별화 규칙
- 문항별 정답률·오개념 통계는 응시자 5명 이상일 때만 교수자에게 보여 준다. 소규모 수업에서 개인 답이 추정되는 것을 막는다.
- 로그에는 가명 ID만 남기고 자유 입력란 내용은 저장 전 이메일·전화번호 패턴을 지운다.
- 기관 간 통계는 기관 이름을 빼고 과목 분야 단위로만 묶는다.

[미확인] 가명정보 처리와 국외 이전 고지의 정확한 법 요건은 개인정보보호위원회 안내와 법률 검토로 확인한다. 위 표는 설계 초안이다.

## 4. 페르미 추정: 시장 규모

[사실] 2025년 4월 기준 고등교육기관 421곳(일반대 189, 전문대 130 등), 재적 학생 301만 6,724명, 교원 24만 624명(전임 8만 6,701, 비전임 15만 3,923)이다([교육부 2025 교육기본통계](https://www.korea.kr/briefing/pressReleaseView.do?newsId=156723307)).

### 4.1 대학 교수자 좌석

| 단계 | 값 | 근거 |
|---|---|---|
| 전체 교원 | 240,624명 | [사실] |
| 교안 중심 시험을 내는 비율 | 50% → 120,312명 | [가정] 실기·논문 중심 과목 제외 |
| 연 이용료 | 1인 6만 원(월 5천 원) | [가정] 학과 예산으로 결제 가능한 소액 |
| 이론상 전체 시장 | 약 72억 원/년 | [계산] 120,312 × 6만 원 |
| 3년 안 현실 목표 | 대학 20곳 × 이용 교원 30명 = 600석 → 3,600만 원/년 | [가정] |

판단: 대학 좌석만으로는 팀 인건비도 나오지 않는다. 대학은 "교수자가 검수한 문항"이라는 신뢰와 사례를 얻는 첫 고객으로 두고, 매출은 4.2에서 찾는다.

### 4.2 에듀테크 출제 API

매출 = 호출 문항 수 × 문항당 단가.

| 단계 | 값 | 근거 |
|---|---|---|
| 고객 | 자격증·공무원·어학·사내교육 콘텐츠 기업 | [가정] 자체 문제은행을 계속 늘려야 하는 곳 |
| 고객당 월 생성 문항 | 2만 문항 | [가정] 신규 과정 개설·개정 대응 |
| 문항당 단가 | 100원 | [가정] 사람이 문항을 쓰고 검수하는 비용보다 낮아야 팔림 |
| 고객 10곳 | 연 2억 4천만 원 | [계산] 10 × 2만 × 100원 × 12개월 |

[미확인] 에듀테크 기업이 실제로 출제를 외주·자동화하는 비용, 이미 쓰는 도구(자체 생성 기능 포함)는 조사 전이다. 경쟁 여부를 공개 자료로 찾지 못했다고 없다고 단정하지 않는다. 다음 조사 대상: 국내 문제은행 서비스와 해외 출제 도구의 가격표.

### 4.3 제공 원가

| 항목 | 값 | 근거 |
|---|---|---|
| 1회 호출 | 5문항, 입력 최대 약 12,000토큰, 출력 최대 4,000토큰 | [사실] 대회 제출 코드의 상한 |
| 단가 | 입력 100만 토큰당 3달러, 출력 15달러 | [가정] 공식 단가 확인 전 |
| 1회 비용 | 약 0.096달러 → 문항당 약 0.019달러(약 27원) | [계산] 1달러 1,400원 가정 |

문항당 100원에 팔면 생성 원가 비중은 약 27%다. 검수 실패로 다시 생성하는 비율, 저장·트래픽·결제 수수료를 더하면 더 낮아진다. 재시도율은 [미확인]이며 파일럿에서 측정한다.

## 5. KPI

| 지표 | 정의 | 왜 이 지표인가 |
|---|---|---|
| 핵심: 주간 확정 문항 수 | 교수자·고객사가 검수 후 "사용"으로 확정한 문항 | 생성 수는 비용만 늘린다. 확정은 쓸모를 뜻한다 |
| 무수정 채택률 | 확정 문항 중 고치지 않고 쓴 비율 | 품질의 직접 신호. 낮으면 생성 비용이 사람 시간으로 옮겨 간다 |
| 오개념 리포트 열람률 | 응시 후 교수자가 리포트를 연 비율 | B2B 차별점이 실제로 쓰이는지 |
| 학생 재풀이율 | 오답 문항을 다시 푼 학생 비율 | 학습 가치의 대리 지표 |
| 갱신률 | 다음 학기 재계약 비율 | 지불 의사의 최종 증거 |

## 6. MVP 범위와 비용

대회 제출판에 이미 있는 것: 교안 페이지 선택, 객관식 5문항 생성, 근거 쪽 표시, 채점·해설·오답 복습.

MVP에서 더할 것
1. 교수자 계정과 강의 단위 문항 묶음(학생은 링크와 가명 ID로 응시).
2. 개념·문제 유형 표와 오개념 기반 오답 선지.
3. 교수자 검수 화면(사용·수정·버림).
4. 응시 5명 이상일 때만 보이는 문항별 정답률·오개념 리포트.
5. 동의 화면, 원문 자동 삭제, 가명 ID 처리.

| 비용 항목 | 3개월 파일럿 | 근거 |
|---|---|---|
| AI 호출 | 1만 문항 × 27원 ≈ 27만 원 | [계산] 4.3 |
| 서버·DB | 월 5만 원 × 3 = 15만 원 | [가정] 소규모 클라우드 |
| 법률 검토(약관·처리방침) | 미정 | [미확인] 견적 필요 |
| 인건비 | 팀원 무급 기준 0원, 유급 전환 시 별도 | [가정] 자금 계획에서 따로 계산 |

## 7. 투자금과 마스터플랜

투자금 규모는 지금 정하지 않는다. 0~1단계는 자체 비용으로 충분하고, 외부 자금은 2단계에서 교수자 확정 문항과 갱신 의사가 확인된 뒤 필요한 인건비만큼 산정한다. 근거 없이 금액을 먼저 적으면 발표에서 가장 먼저 무너지는 숫자가 된다.

| 단계 | 기간 | 할 일 | 넘어갈 조건 |
|---|---|---|---|
| 0. 권리·동의 설계 | 2주 | 약관·처리방침 초안, 원문 삭제·가명 ID 구현 | 법률 검토 의견 확보 |
| 1. 교수자 파일럿 | 1학기 | 교수자 3명, 과목 3개. 확정 문항·무수정 채택률 측정 | 무수정 채택률과 재사용 의사 확인 [가정 기준: 50% 이상, 3명 중 2명 재사용] |
| 2. 학과 계약 | 다음 학기 | 학과 1곳 유료 계약, 오개념 리포트 사용 측정 | 갱신 의사 |
| 3. 에듀테크 API | 2단계와 병행 조사 | 콘텐츠 기업 2곳 인터뷰, 시험 계약 1곳 | 문항당 단가 수용 확인 |
| 4. 확장 | 이후 | 기관 다수·과목 분야 확장 | 1~3 숫자로 투자금 산정 |

## 8. 발표 자료에 넣을 순서

심사위원이 예시로 보낸 IR 자료의 흐름(고객 문제 → 해결책 → 경쟁 비교 → 시장 규모 → 매출 = 트래픽 × 단가 → KPI·일정·재무)에 맞추면 다음 장 구성이 된다.

1. 교수자의 문제: 매 학기 연습문제를 새로 만드는 시간, 학생이 어디서 틀리는지 모름.
2. 해결: 교수자 자료로 개념·유형 기반 문항 생성, 검수, 오개념 리포트.
3. 신뢰: 자료는 권리자만 넣는다, 학생은 가명, 5명 미만 통계 비공개, 원문 자동 삭제.
4. 경쟁 비교: [미확인] 조사 뒤 작성.
5. 시장: 4절 계산을 가정과 함께 그대로 보여 준다.
6. 매출 구조: 좌석 × 단가(대학) + 문항 × 단가(API).
7. KPI와 단계별 계획: 5·7절.

## 9. 남은 일

- 법률 검토: 저작권 이용 범위, 가명정보·국외 이전 고지 요건.
- 경쟁 조사: 국내외 출제 도구와 문제은행 서비스의 기능·가격.
- 교수자 인터뷰 3명: 연습문제 준비 시간, 오개념 리포트 필요 여부, 결제 주체(개인·학과).
- 팀 결정: 이 재설계는 대회 뒤 작성한 개인 검토안이다. 팀 원본 PRD에는 반영하지 않았다.
